## 🚀 Projets Phares  

### 🤖 [Tuteur Intelligent pour Étudiants Marocains](https://github.com/taghifarah02) (En cours - PFA)
Système de tutorat intelligent local et offline basé sur l'IA générative  
- 🧠 Architecture **RAG** (Retrieval-Augmented Generation) pour des réponses contextualisées  
- 💬 Utilisation de **LLM** avec fine-tuning (SFT) pour adaptation au contexte éducatif marocain  
- 🤝 **Agents IA** orchestrés avec LangGraph pour tâches complexes  
- ⚡ Backend FastAPI + Base vectorielle ChromaDB  
- 🖥️ Interface desktop avec Electron.js  
- **Tech**: LLM, RAG, SFT, LangChain, LangGraph, llama.cpp, FastAPI, ChromaDB, Electron.js

### 🚗 [Système d'Aide à la Conduite (ADAS)](https://github.com/taghifarah02/ADAS-Project)
Système avancé d'assistance à la conduite - Projet de Fin d'Études  
- 🎯 Classification des panneaux de signalisation avec **CNN PyTorch** (haute précision)  
- 🛣️ Détection des voies de circulation en temps réel avec **OpenCV**  
- 🎮 Simulation et tests dans **CARLA Simulator**  
- 🔍 Traitement d'images avancé pour conditions variées  
- **Tech**: PyTorch, OpenCV, NumPy, CARLA Simulator, Deep Learning, Computer Vision

### 💰 [ExpensePro - Gestion Intelligente des Notes de Frais](https://github.com/taghifarah02/ExpensePro)
Application mobile avec saisie automatique par OCR  
- 📱 Application **cross-platform** (iOS/Android) avec Flutter  
- 🔍 **OCR** pour extraction automatique des données de reçus  
- 💾 Base de données locale SQLite pour accès offline  
- 📊 Visualisations et statistiques des dépenses  
- **Tech**: Flutter, Dart, SQLite, OCR, Computer Vision
